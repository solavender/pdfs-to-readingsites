# 正式阅读器功能约定

复用统一内容和批注逻辑，风格只负责呈现。下列功能全部纳入正式阅读器；具体布局按选择适配。

## 阅读与定位

1. 提供层级目录、当前章节、全文搜索及返回匹配段落。搜索可涵盖原文、译文与批注，但结果标明所在部分。
2. 保存上次阅读位置及主题、字号、行距、栏宽。刷新恢复；手机单栏、桌面可多栏。
3. 原文／处理后文字有可检查的段落映射；提供段落展开与宽屏双栏对照。不是翻译任务时以“原始／整理后”标识；确实无差异时不制造伪对照。
4. 引用复制包含选中文字、实际题名、章节、已核实的原刊页及物理页、实际 DOI（若有）。缺失字段省略或标待核对，不编造。

## 高亮与批注

1. 至少四种可辨识颜色；支持高亮、添加批注、编辑、改色、删除，并能定位原文。
2. 采用稳定段落 ID 加精确文本／上下文锚点。跨格式、跨段落的选择不能损坏 DOM。
3. 为重叠标注定义明确行为：合并、分段或提示编辑已有标注；不能静默覆盖或抛异常。
4. 按章节、颜色、关键词筛选；批注面板可批量选择导出，显示数量与来源。
5. 点击已有高亮可编辑；触屏长按与键盘操作可用，不依赖 hover。

## 保存、迁移与导出

1. 默认本设备自动保存，可用 IndexedDB 或 localStorage；记录文档 ID、schema 版本、修订号。写入失败时显式显示未保存，提供下载，不能仍显示成功。
2. 导出完整 JSON：批注、阅读位置、设置、用户校订、原图补充和未定位记录。导入校验 schema、文档 ID 和类型，不执行输入代码。
3. 合并导入按批注 ID 与更新时间处理，并向用户说明冲突。删除需 tombstone 或明确恢复策略，防止旧备份无提示地复活已删除记录。
4. 导入前保留当前状态备份。新设备可恢复，不依赖原机器的路径或私人接口。
5. 导出含批注的自包含 HTML。序列化干净正文与状态，不把已着色 DOM 和同一批注再次双重应用；在无本地存储的新环境中测试恢复。
6. 导出全部／筛选／选中笔记为 Markdown 与真正的 DOCX。若只能提供 Word 可打开的 HTML `.doc`，必须标明实际格式，不称其为原生 DOCX。使用有维护的 DOCX 实现或可用 documents 技能。
7. 明确本地保存和跨设备同步的差别；文件改名、file URL 与 https 站点可能是不同存储源。迁移通过显式备份，不宣称托管后自动云同步。

## 学习辅助与内容质量

- 术语表列出原词、译法、简短释义和出现位置；点击回到文章。译注与原作者文字视觉区分。
- 图表支持放大、适配窗口、中文／原图切换。离线图片与字体依赖实际打包，不能使用即将过期的链接。
- 检查面板显示内容覆盖、待核对页、术语不一致、未定位标注及缺失原图。统计结构数量不等于完成翻译质量核验。
- 保留脚注回跳、参考文献及公式；复杂公式无法可靠转换时提供原始清晰图并注明。
- 不在界面泄露工具调用、后台凭据或流程内部细节；必要的来源与限制说明用读者能理解的语言。

## 工程边界

纯离线 HTML 不能直接调用本地 Python 完成 MarkItDown 转换。本 skill 的提取步骤由代理运行，HTML 接收完成的数据。用户若要求在线上传 PDF 自动转换，那是新增后端任务，不假装已有。

正式应用不得直接采用预览页“刷新即清空”的演示状态。内容不多时优先单文件；图片量大时可交付明确完整的资源包。使用实际可用库，处理离线依赖和 CSP，避免为了界面而扩大功能范围。
