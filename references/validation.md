# 验收与恢复

## 转换和处理

- 核对输入页数与 pages.json 数量；页码连续且来自实际分页。
- 从前、中、后以及包含表格／公式／脚注的页面抽查；对已发现疑点逐项核对，不用抽样宣称全书逐字无误。
- 全文任务核对源块覆盖：没有未处理章节、截断末尾、跨页重复或参考文献遗漏。未完成时记录实际范围。
- 扫描页、空白页和图片页明确分类；失败提取不标为已翻译。
- 检查术语一致、作者年份引文、图号、表号、参考文献、数字与公式。
- 原文对照必须来自 PDF 提取／人工核对，不得由译文回译。

## 风格流程

- 文本处理完毕再询问；四个风格全部可见。
- 已选风格不重复问；只有用户授权自行决定才可默认选择。
- 预览无私人链接依赖；确认前不交付一个假定选择的最终阅读器。

## 交互回归

用一个有跨段落、表格、图注和重复句的实际样本验证：

- 创建高亮 → 编辑批注 → 更改颜色 → 筛选 → 定位原文 → 刷新后恢复。
- 改字号、主题、行距与栏宽，锚点仍正确；跨段落标注不破坏 DOM。
- JSON 导出 → 新环境导入，记录与原文一致；错误文档、坏 JSON、存储拒绝显示清楚的失败状态。
- 含批注 HTML → 清空浏览器存储／新环境打开，无重复标注且备注保留。
- 删除记录后导入旧备份的行为有明确定义；歧义锚点保留为未定位，不自行猜测。
- Markdown 和 Word 导出的内容与筛选选择一致，来源可追溯。
- 阅读位置恢复、搜索回跳、原文对照、图表切换都可操作。
- 检查桌面和手机尺寸、200% 字体放大、键盘焦点、触屏选择、夜间对比度；无意外横向溢出。

浏览器不可用时可做语法、数据映射及 DOM 行为检查，但报告“未完成视觉检查”，不伪称通过。用户未把视觉 QA 设为发布条件时，不因此阻止已验证产物的交付。

## 交付

输出路径／链接真实可用；独立文件已保存。网站仅在部署返回成功及正式 URL 后报告已发布。说明真正待补的原文／图片／页码，不把入口实现等同于资料齐备。

中断恢复读取 source.md、processed.md、映射与状态：从最后完成阶段继续，不再次提取、收费或询问已回答的问题。
